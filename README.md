# Dashboard de Vendas do Xbox

Projeto de dashboard feito no Excel com dados de assinaturas do Xbox Game Pass.

## Arquivo

- `Dashboard_Vendas_Xbox.xlsx`: arquivo final com as abas `Bases`, `Cálculos` e `Dashboard`.

## Como usar

1. Abra o arquivo no Excel.
2. Consulte a aba `Dashboard` para ver os indicadores e gráficos.
3. Para atualizar os dados, altere a tabela da aba `Bases` e atualize as tabelas e gráficos no Excel.

As análises mostram o faturamento por tipo de assinatura, renovação automática e vendas dos passes EA Play e Minecraft.
